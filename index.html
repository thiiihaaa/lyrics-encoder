User Guide

ဒီ Web App လေးက ဘာလဲ?

အားလုံးပဲ မင်္ဂလာပါ။ ဒီ Web App လေးကတော့ သီချင်းဘာသာပြန်ရတာ ဝါသနာပါပေမယ့် Encoding လုပ်ရမှာ ပျင်းတဲ့သူတွေအတွက် ရည်ရွယ်ပြီး ဖန်တီးထားတာပါ။ Alight Motion မှာ တိုက်ရိုက်ထည့်သွင်းအသုံးပြုနိုင်တဲ့ XML File ကို အလိုအလျောက် ထုတ်ပေးမှာ ဖြစ်လို့ သင့်ရဲ့ Editing အချိန်တွေကို အများကြီး သက်သာစေမှာပါ။

ဘယ်လို အလုပ်လုပ်သလဲ?

သင် ဘာသာပြန်ချင်တဲ့ သီချင်းရဲ့ ခေါင်းစဉ် (Song Title) နဲ့ အဆိုတော်အမည် (Artist Name) ကို ရိုက်ရှာလိုက်ရုံပါပဲ။ lrclib.net ကနေ Timing ကိုက်ထားပြီးသား Lyrics တွေကို ရယူပေးပြီး သင့်အတွက် အဆင်သင့်သုံးလို့ ရမယ့် XML File အဖြစ် ပြောင်းလဲပေးမှာပါ။

⚠ သတိပြုရန်

ဒီ App က Video တစ်ပုဒ်လုံးကို ဖန်တီးပေးတာ မဟုတ်ဘဲ စာတန်းထိုး XML ကိုပဲ ထုတ်ပေးတာပါ။ ဒါကြောင့် Background Photo၊ Text Animation နဲ့ သီချင်းတွေကိုတော့ Alight Motion ထဲမှာ မိမိ စိတ်ကြိုက် ပြန်လည်ပြင်ဆင်ပေးဖို့ လိုအပ်ပါတယ်။

1 သီချင်းဖိုင် ထည့်သွင်းခြင်း
  • Song Section ကိုဖွင့်ပြီး Upload Song ကို နှိပ်ပါ
  • MP3, WAV, M4A ဖိုင်များကို အသုံးပြုနိုင်ပါသည်
  • သင်ရှာလိုသော Song Title နှင့် Artist Name ကို မှန်ကန်အောင် ရိုက်ထည့်ပါ
2 Lyrics ရယူခြင်း
  • Get Synced Lyrics ကို နှိပ်ပါက lrclib.net မှ Timing ကိုက်ပြီးသား စာသားများကို အလိုအလျောက် Fetch လုပ်ပေးပါမည်
  • Manual Lyrics: ရှာမတွေ့ပါက [mm:ss.xx] စာသား ဆိုသည့် LRC Format ဖြင့် ကိုယ်တိုင် ရိုက်ထည့်နိုင်ပါသည်
  • Translation: မြန်မာဘာသာပြန် ထည့်လိုပါက Translation / Caption တွင် ထည့်သွင်းပါ
ဘာသာပြန်စာသားကို မူရင်းစာသားရဲ့ Format အတိုင်း (Timing အပိုင်းအခြားတူအောင်) ထည့်ပေးခြင်းက Sync ဖြစ်ဖို့ အကောင်းဆုံးနည်းလမ်းပါ။
3 Style နှင့် Position ချိန်ညှိခြင်း
  • Styling: Font အမျိုးအစား၊ အရွယ်အစားနှင့် အရောင်များကို စိတ်ကြိုက် ရွေးချယ်ပါ
  • Position: Canvas ပေါ်တွင် စာသားကို နှိပ်ဆွဲပြီး နေရာချနိုင်ပါသည်
  • Resolution & FPS: Alight Motion Project setting နှင့် တူအောင် ချိန်ညှိပေးပါ
သတိပြုရန်: ဒီမှာသုံးတဲ့ Font သည် သင့်ဖုန်း Alight Motion ထဲတွင်လည်း ရှိနေရန် လိုအပ်ပါသည်။ အောက်မှ Font Package ကို Download ရယူပြီး Import လုပ်ထားပါ။

4 Timing တိကျအောင် ညှိခြင်း
  • Preview: Player တွင် သီချင်းဖွင့်ပြီး စာသားများ အချိန်ကိုက်၊ မကိုက် စစ်ဆေးပါ
  • Adjustments: စာသား စောနေ/နောက်ကျနေပါက −0.5s / +0.5s ခလုတ်များဖြင့် ညှိနိုင်ပါသည်
  • Trimming Mode (အကြံပြုချက်): LRC Format သည် စာသားစဆိုချိန်ကိုသာ သိပြီး အဆုံးသတ်ချိန် မပါဝင်ပါ။ Trimming Mode ကိုဖွင့်ကာ စာသားတစ်ကြောင်းဆုံးတိုင်း Tap to Trim ကို နှိပ်ပေးခြင်းဖြင့် ပိုမိုသေသပ်သော XML ကို ရရှိပါမည်
5 Export လုပ်ခြင်း
  • အားလုံးပြီးပါက Export Section မှ Export XML ကို နှိပ်ပါ
  • ရရှိလာသော .xml ဖိုင်ကို Alight Motion တွင် Import Project လုပ်ပြီး အသင့်အသုံးပြုနိုင်ပါပြီ
  • Cloud Sync: ဖိုင်တွေကို Cloud ပေါ်မှာ သိမ်းထားချင်ရင်တော့ Account ဖွင့်ထားဖို့ အကြံပြုပါတယ် — ဘယ်အချိန်မဆို ပြန်လည် Download ဆွဲနိုင်မှာပါ
Creator's Note — ဒီ App လေးကို Vibe Coding နဲ့ ဖန်တီးထားတာဖြစ်လို့ အဆင်မပြေတာလေးတွေ ရှိရင် သည်းခံပေးဖို့ တောင်းဆိုချင်ပါတယ်။ အားလုံးပဲ အချိန်ကုန်သက်သာစွာနဲ့ Lyric Video လှလှလေးတွေ ဖန်တီးနိုင်ကြပါစေ!
